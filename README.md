# Breaking Data Analytics

Projeto desenvolvido para praticar análise de dados utilizando Python.

## Objetivo

Analisar dados de eventos de Breaking e gerar insights através de consultas e visualizações gráficas.

## Tecnologias Utilizadas

- Python
- Pandas
- Matplotlib
- Git
- GitHub

## Estrutura do Projeto

breaking-data-project/

├── dados/

│ └── eventos.csv

├── scripts/

│ ├── analise.py

│ └── grafico.py

├── README.md

├── requirements.txt

└── .gitignore

## Funcionalidades

- Leitura de arquivos CSV
- Contagem de categorias
- Filtros por cidade
- Ranking por pontuação
- Estatísticas (média, máximo e mínimo)
- Gráficos de visualização
